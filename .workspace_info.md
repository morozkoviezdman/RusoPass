# 🎯 Рабочая среда — /root/workspace

## Модель работы
Все файлы, вложенные в работу, должны сохраняться в **/root/workspace**,
а не в ~/.hermes (в том числе файлы подсказок).

## Проверка местоположения
```bash
pwd  # Должно быть /root/workspace
# или
ls -la /root/workspace
```

## Артефакты сеанса
- Ответы на запросы пользователя
- Результаты поисков, отчёты, листинги
- Временные файлы: /tmp/ или /root/workspace/tmp/

## В рабочей ветке НЕЛЬЗЯ:
- Сохранять API ключи, токены или пароли в явном виде
- Класть временные или промежуточные данные (используйте /tmp/)

## Для глубоких подзадач используйте:
- /tmp/ для временных файлов
- /root/workspace/ для финальных ответов
- session_archive/ для архивных выкладок разговора
