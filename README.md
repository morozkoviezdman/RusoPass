# RusoPass

Панель транслятора раскладок для ввода текста в других раскладках.

## Быстрый старт

Откройте `index.html` в браузере. Достаточно одного файла — ничего устанавливать не нужно.

## Как вводить пароль на телефоне с другой раскладкой (как на ПК)

### Основной принцип
1. Откройте RusoPass в браузере на телефоне (Chrome / Safari)
2. Перейдите на нужную раскладку (русская или английская)
3. Введите пароль в поле «Ввод текста» — трансляция будет выводиться в поле «Вывод»
4. Скопируйте текст из поля вывода и вставьте в поле ввода пароля

### Пример: пароль на русской раскладке, когда сейчас английская
| Нажимаете на «русский» | Вводите | Транслируется в |
|------------------------|---------|-----------------|
| русский | `фывап` | `asdfg` |
| русский | `йцукен` | `qwerty` |

### Варианты использования
- **Пароль + A** → `oofza` (если сейчас Английская)
- **Пароль 123** → `sdc` (если сейчас russian)
- **E-mail** → `d1m4@mail.ru` (если сейчас русская)

### Советы
- Дважды коснитесь поля ввода, выберите текст, скопируйте
- Вкл. режим звезд → звездочки вместо букв
- Включите «Полный текст» чтобы видеть результат

> Совет: если клавиатура сбивается — переключите раскладку на телефоне на Английскую, введите текст, а в поле вывода Русская.
> 
 Как добавить на свой рабочий экран?
iOS Safari — поделитесь (кнопка Share), выберите «Добавить на домашний экран», дайте имя и нажмите «Добавить».
Android Chrome — меню (3 точки) → «Добавить на экран» → «Добавить».
